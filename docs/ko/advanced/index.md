고급 사용법은 차트의 기본 `values.yaml`에서 시작해 부분 오버레이로 환경에 맞춥니다.
Hermes는 버전별 기본값을 제공하고 여러분의 환경은 시크릿을 별도로 주입합니다.

## 목적별로 선택하기

- **차트를 설정하려면:** 설정 모델, Secret, 영속성, 테스트를 먼저 확인하세요.
- **모델을 연결하려면:** 제공자 페이지에서 공개 API와 GitHub 기기 로그인 플로우를 다룹니다.
- **프록시나 봇을 연결하려면:** 통합 페이지에서 LiteLLM, Discord, Telegram, 보호된
  대시보드를 다룹니다.
- **에이전트를 조율하려면:** 실전 패턴과 팀 가이드에서 시크릿 매니저, 공유 스토리지,
  협업, 팀을 다룹니다.

실제 키를 오버레이에 커밋하지 마세요. 각 예제는 필요한 Secret과 플레이스홀더
값을 사용한 설치 명령을 문서화합니다.
