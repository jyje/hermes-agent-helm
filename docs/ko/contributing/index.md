# 기여하기

기여 가이드는 모든 언어에서 하나의 영문 문서를 기준으로 유지합니다.
[영문 기여 가이드](https://jyje.github.io/hermes-agent-helm/contributing/)에서
브랜치·PR·검증·Changeset·릴리즈·번역 정책을 확인하세요.
[GitHub 원문](https://github.com/jyje/hermes-agent-helm/blob/main/CONTRIBUTING.md)도
같은 기준 문서입니다.

다른 한국어 기여 문서는 계속 제공합니다.

- [로컬 개발](local-development.md)
- [CI 가이드](ci.md)
