문서 사이트와 Helm 저장소는 서로 덮어쓰지 않고 같은 GitHub Pages를 공유합니다.
Helm 클라이언트는 이 인덱스를 사용합니다. 아래 명령으로 직접 살펴보거나
저장소를 추가할 수 있습니다.

```bash
helm repo add hermes-agent https://jyje.github.io/hermes-agent-helm
helm repo update
```
