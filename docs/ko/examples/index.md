모든 예제는 `charts/hermes-agent/values.yaml`에 대한 오버레이입니다. 의도적으로
부분적인데, Hermes가 버전별 기본값을 채우고 여러분의 환경이 시크릿을 별도로
주입하기 때문입니다.

## 목적별로 고르기

- **모델을 연결하려면:** 제공자 페이지에서 공개 API와 GitHub 기기 로그인 플로우를 다룹니다.
- **프록시나 봇을 연결하려면:** 통합 페이지에서 LiteLLM, Discord, Telegram, 보호된
  대시보드를 다룹니다.
- **에이전트를 조율하려면:** 고급 페이지에서 시크릿 매니저, 공유 스토리지, 협업,
  팀을 다룹니다.

실제 키를 오버레이에 커밋하지 마세요. 각 예제는 필요한 Secret과 플레이스홀더
값을 사용한 설치 명령을 문서화합니다.
