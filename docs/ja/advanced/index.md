基本の `values.yaml` に部分的なオーバーレイを適用して構成します。Hermes がバージョン固有のデフォルトを提供し、シークレットは環境から別途注入します。

## 目的から選ぶ

- **チャートの設定:** 設定モデル、シークレット、ストレージ、テストを理解します。
- **モデルへの接続:** プロバイダーのページでは公開 API と GitHub デバイスログインを説明します。
- **プロキシやボットへの接続:** 連携のページでは LiteLLM、Discord、Telegram、保護された dashboard を説明します。
- **エージェントの調整:** パターンとチームのガイドではシークレット管理、共有ストレージ、連携、チームを説明します。

実際のキーをオーバーレイに入れてコミットしないでください。各サンプルに必要な Secret とプレースホルダーを使ったインストールコマンドを記載しています。
