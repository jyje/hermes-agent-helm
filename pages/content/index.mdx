## Install

```bash
helm repo add hermes-agent https://jyje.github.io/hermes-agent-helm
helm repo update
helm install hermes-agent hermes-agent/hermes-agent \
  --namespace hermes-agent --create-namespace \
  --set-string env.OPENAI_API_KEY='sk-...' \
  --wait
```

The chart is also published as an OCI artifact at `oci://ghcr.io/jyje/hermes-agent-helm/hermes-agent` — see the [main README](https://github.com/jyje/hermes-agent-helm#getting-started) for both options and the full configuration reference.
